# Object-Oriented Programming in Java 

This repository contains Java programs covering the fundamental concepts of Object-Oriented Programming (OOPs).
It is designed for beginners to understand core Java OOP concepts through simple examples and practice programs.



##  Topics Covered

### 1. Objects and Classes

* Creating classes and objects
* Instance variables and methods
* Accessing object properties

### 2. Method Overloading

* Multiple methods with the same name
* Different parameter lists
* Compile-time polymorphism

### 3. Constructors

* Default constructor
* Parameterized constructor
* Copy constructor


### 4. Access Modifiers

* `public`
* `private`
* `protected`
* Default access

### 5. Packages

* Creating packages
* Importing packages
* Organizing Java files

### 6. Inheritance and Method Overriding

* Single inheritance
* Multi-level inheritance
* Hierarchial inheritance
* Reusing parent class properties
* Runtime polymorphism through method overriding

### 7. Use of `super` Keyword

* Accessing parent class variables
* Calling parent class methods
* Calling parent class constructors

### 8. Static Keyword

* Static variables
* Static methods
* Static blocks

### 9. Final Keyword

* Final variables
* Final methods
* Final classes

### 10. Abstract Class

* Abstract methods
* Abstract classes
* Achieving abstraction

### 11. Interface

* Implementing interfaces
* Multiple inheritance using interfaces

### 12. Use of `this` Keyword

* Referring to current object
* Constructor chaining
* Differentiating instance and local variables

### 13. Anonymous Class

* Creating anonymous classes
* Method implementation without named class

### 14. Inner Class

* Member inner class
* Accessing outer class members

### 15. Anonymous Inner Class

* Defining and using anonymous inner classes
* Short-term object implementation

### 16. Abstract Anonymous Class

* Implementing abstract class using anonymous object
* Runtime method definitions

### 17. Wrapper Class

* Primitive to object conversion
* Autoboxing and unboxing
* Useful wrapper class methods



##  Technologies Used

* Java
* VS Code 



##  How to Run

1. Clone the repository

```bash
git clone <your-repository-link>
```

2. Open the project in your IDE

3. Compile the Java file

```bash
javac FileName.java
```

4. Run the program

```bash
java FileName
```
